# @breakline/cli

Command-line interface for [Breakline](https://github.com/krippy2k/breakline). Finds behavioral changes inside TypeScript and JavaScript diffs.

```bash
npm install -g @breakline/cli
breakline analyze main..HEAD
```

Or without a global install:

```bash
npx @breakline/cli analyze main..HEAD
```

See the [repository README](https://github.com/krippy2k/breakline#readme) for commands and examples.
